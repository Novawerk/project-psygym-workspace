# 文案规范和中英文对照

## 规范

- 短句。「我们」，现在时。一句话说一件事。
- 先写中文，再写英文。意思一致，不逐字翻。英文用英式拼写（practise / counselor 保持现有写法）。
- 称呼用户「你」/ you。称呼 AI 扮演的人「来访者」/ the client，不叫「病人」「患者」。
- 不用：治愈、治疗效果、诊断、保证、最好的、革命性；不用 leverage / ecosystem / stakeholders / synergy / disrupt / transform。
- 安全相关的话平静地说，不用感叹号，不用全大写，不用红色。
- 按钮用动词开头：「开始会谈」「结束并查看督导」，不用「确定」「OK」。
- 数字和单位：「约 15 分钟」/「About 15 min」。
