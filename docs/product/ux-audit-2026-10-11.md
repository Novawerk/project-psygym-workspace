## 🟠 影响体验

### A. 隐私说明说「邀请码只存在这台手机上」，不准确

- **在哪：** 我的 → 隐私说明 →「你们收集什么？」（`en-light-04-P3.png`）
- **怎么复现：** 打开隐私说明，看这一条。
- **问题：** 邀请码每次请求都放在请求头里发到我们的服务器，用来校验和限流（`api-contract.md`）。「只存在这台手机上」和实际不符。
- **影响：** 隐私说明说得不准，和安全文档「说清楚」的原则冲突。
- **建议改成：**「邀请码：每次请求会发给我们的服务器，用来校验和限流。你选的语言：只存在这台手机上。没有账号，不收集姓名、手机号、位置。」本 PR 已改 `copy.md` 和 `screens.md`，移动端同步。

### B. 删除单场记录后跳回首页，不是记录列表

- **在哪：** 记录 → 点一场 → 右上删除 → 确认。（`en-light-19-M2-delete.png` → `en-light-20-M1-empty.png`）
- **怎么复现：** 从底栏「记录」进一场，删除。
- **问题：** 删完落在「练习」首页，底栏选中的也是「练习」。用户以为删错了，或者要再点一次「记录」才能确认已经删掉。
- **原因：** `App.kt:212-215` 删除后 `popBackStack()`。从底栏进的详情页，返回栈里上一页是首页。
- **建议：** 删除后回到「记录」列表，底部给一个提示条「已删除」。

### C. 来访者结束会谈后，计时还在走

- **在哪：** 会谈页，来访者结束之后。（`en-light-12-S1-client-ended.png`）
- **怎么复现：** 演示数据下发一句带 `#end` 的话，来访者会结束会谈；看顶栏的计时。
- **问题：** 13 秒后计时从 02:25 走到 02:38。
- **影响：** 会谈已经结束，时间还在加，看起来像还在进行。报告和记录里的时长也会偏大。
- **建议：** 收到 `session_end` 时停表，记录用这一刻的时长。

### D. 报告开始出字后，「督导正在读你们的对话…」就消失了

- **在哪：** 督导报告，生成中。（`en-light-13-R1-generating.png`）
- **问题：** 第一段出来以后，那张提示卡就没了，只剩正文下面一个很小的转圈。真模型写一份报告要几十秒（目前没有耗时数据，见 #G），中途停顿时看不出还在写。
- **建议：** 写完之前，正文下面一直留一行「督导还在写…」和转圈；写完（`turn_end`）再出底部按钮。

### E. 病例列表加载失败时，说「这个病例暂时不可用」

- **在哪：** 首页病例小节、病例列表。（`en-light-24-C1-offline.png`）
- **怎么复现：** 关掉演示数据。本机 8787 端口正被 Novawerk 主仓库的 API 开发服务占着，`/cases` 返回 404。
- **问题：** 列表根本没加载出来，提示却是单个病例的 `case_not_found` 文案。
- **影响：** 正式环境里少见，但一旦出现，用户不知道该做什么。开发时 8787 端口和 Novawerk API 冲突，也容易误判问题。
- **建议：**
  - 列表加载失败统一显示「病例加载不出来，请稍后再试」+ 重试；
  - `case_not_found` 只在进入某个病例时用；
  - PSYGYM 后端本地换一个端口，或者在 README 里写明。

### F. 引导第 3 页，「跳过」和语言切换各有两处

- **在哪：** 引导「准备开始」。（`en-light-05-O3.png`）
- **问题：**
  - 右上有「跳过」，底部有「先跳过」；
  - 右上有「中 / EN」切换，页面里有「界面语言」单选。
  - 两个跳过的结果一样；两个语言控件改的是同一个设置，但样子不同。
- **影响：** 新手会犹豫该点哪个，也不确定右上的「中」是不是另一个设置。
- **建议：** 这一页去掉右上的「跳过」和语言切换，只留页面里的语言单选和底部两个按钮。

### G. AI 督导报告：偏长、引号里有非原话、格式不统一

来源：测试成员 10/10 的真模型记录。

- **中文报告偏长：** 两份都约 1150 字（含标点），超过 600–1000 字的约定，手机上要滑三四屏。建议：「需要改进」最多 3 条，合并同类。
- **引号里放了不是原话的话：** 例如把概念「先理解再干预」放进「」。学员会以为是自己说过的，和验收 C2「引用原话」冲突。建议提示词里写明：「」只放逐字原话。
- **英文报告格式不统一：** 有的「需要改进」用「编号 + 粗体小标题」，有的是普通编号，同一个 App 里样子不一样。建议固定一种格式，不加粗体标题。
- **记录里没有耗时：** 首字时间、总时长都没有，判断不了等待会不会太长（#D）。建议质量脚本把这两项写进 SUMMARY。
- 这几条请转给后端（提示词）和测试（脚本）。来访者这边没发现问题：守住了角色，没给建议，没有中英混杂。

### H. 打开 App 时切换系统深色模式，状态栏图标看不清

- **在哪：** 任意页面，App 开着时切换系统深浅色。（`zh-dark-02-O2.png`）
- **问题：** 页面变成深色了，状态栏的时间和电量还是深色图标，几乎看不见。换一页后恢复正常（`en-dark-02-C2.png`）。
- **建议：** 主题变化时同步更新状态栏图标颜色。

### I. 还没有报告反馈（👍/👎）和举报入口

- **在哪：** 督导报告页、会谈页长按。（`en-light-14-R1-done.png`）
- **说明：** 按计划这两项在第 2、3 批，不是 bug。列在这里是提醒：正式上架前必须有举报（Google Play 要求，D8）。到时隐私说明要同步加「评价」「举报」两问，文案已经在 `copy.md` 里。
