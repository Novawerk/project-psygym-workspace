# 实时语音会谈

**状态：** 方向已定：用 ElevenLabs，做进产品（2026-10-30，用户）。功能做好了，默认关，没配密钥时入口不显示。决定和实测数据见 [ADR 0013](../decisions/0013-voice-elevenlabs.md)。

**一句话：** 咨询师像打电话一样和 AI 来访者说话。来访者用声音回答，可以被打断。会谈结束后照旧出督导报告。

和[按住说话](./voice-input.md)的关系：按住说话不动，是打字模式的一部分，声音不出手机。语音会谈是另一种会谈方式，声音会发给 ElevenLabs，开始前要单独同意。

---

## 1. 怎么工作

ElevenLabs 负责听和说，来访者说什么由我们的后端决定。

```
手机 ──声音──▶ ElevenLabs agent ──文字──▶ 我们的 /voice/llm ──▶ 模型服务
     ◀─声音──  （转文字、合成声音）◀─文字── （提示词、病例、end_session、判断）
```

所以提示词和安全规则只有一份，打字和语音用的是同一个来访者。语音只多一段说明：写的每个字都会被读出来，话要像说出来的，要多说一些（`apps/api/src/voice.ts`）。

## 2. 用户怎么走

界面规格在 [voice-session-design.md](./voice-session-design.md)，这里只说大意。

1. **病例简介页（C2）**：主按钮上面多一个「打字 / 语音」切换，记住上次选的。服务器没开语音时看不到，页面和以前一样。
2. **单独同意（V1）**：第一次选语音时出现，默认不勾选，写清发给谁、发到哪、存多久、怎么撤回，「改用打字」和主按钮并列。可以在「我的」里撤回。
3. **麦克风权限**：没给过就问一次。被拒绝时可以去设置，也可以改用打字。
4. **通话页**：来访者状态、麦克风开关、结束按钮，通话中不显示文字，督导 Chip 照旧，「需要帮助」常驻，底部一行写明这是练习。屏幕保持常亮。
5. **结束**：弹 S2（打开时自动关麦）。用转写走现有的 `/supervision` 出报告，练习记录照常存在手机上，报告和记录上标「语音会谈」。
6. **来访者挂断**：伤害性的话出现第二次时，来访者说一句结束语，然后 `end_call` 挂断。页面显示「来访者结束了这次会谈」，只留「结束并查看督导」。

**断线和离开：** 断线、切到后台、打开「需要帮助」都会挂断，因为求助时不能还有来访者的声音，没人听的通话也在计费。文字还在：可以「打字继续」（转到打字模式，上文接得上，最后一句没回的话来访者会接着回），也可以看报告。还没说过话就断了，就重试或改用打字。

## 3. 这一版不做

- 通话页的音量动画、波形、触感。
- 按地区开关：开了就是所有人都能看到。
- 带上文重新接通。ElevenLabs 的新通话没有上文，所以断线转打字。
- 通话最长 20 分钟（agent 的设置），到时间自动结束。

## 3a. 来访者说话要像真实对谈

这是最重要的验收标准，做法和数字见 ADR 0013。量的办法：

```bash
node scripts/voice-test/quality.mjs .env 8787 cbt-depression-anxiety-01 8 out.json
```

咨询师的话全是编的。真实对谈不进仓库、日志、ElevenLabs 或模型服务。最终标准是对着原文盲读，能不能分出来。

## 3b. 在模拟器上测

模拟器没有麦克风，开了宿主音频还会在通话开始时卡死（macOS CoreAudio）。这样测：

```bash
emulator -avd <avd> -no-window -no-audio
adb shell run-as io.novawerk.psygym sh -c 'cat > files/voice-call-test.txt'   # 每行一句咨询师的话
```

调试版读到这个文件，会每 8 秒把一句当作咨询师的话发出去（`VoiceTestAudio.kt`，正式版没有这段）。这样走的是真的 ElevenLabs、真的 WebRTC 和真的后端，只是没有声音进出。要测听感，用真手机。

## 4. 打开之前要做

顺序不能反。详细见 [ADR 0013](../decisions/0013-voice-elevenlabs.md) 的「打开之前」。

1. 确认 ElevenLabs DPA 的合同主体和日期（用户说已签好，2026-10-30），填上传输依据。
2. 隐私政策、隐私标签、数据安全表、Review Notes 按 `docs/release/` 改好并提交。
3. 建生产用的 agent，把 Custom LLM 指向生产环境的地址。
4. 在生产环境配三个环境变量。配上的那一刻入口就会出现。

大陆可用性暂不考虑（用户，2026-10-30）。

## 5. 为什么不是豆包或千问

2026-10-25 曾打算比试端到端模型（`docs/realtime-voice` 分支，PR 124）。用户 2026-10-30 定了 ElevenLabs。主要差别：ElevenLabs 让我们保留自己的后端当大脑，长提示词和结束判断都不用改；端到端模型的人设有长度限制（豆包 O2.0 最多 4000 字，我们的提示词加病例约 2.8 万字），结束判断也要另做。代价是声音发到美国，国内连接和合规都比国内厂商差，见 [ADR 0013](../decisions/0013-voice-elevenlabs.md)。
