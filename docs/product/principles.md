# 产品原则

拿不准怎么做时，按这几条判断。排在前面的优先。

## 1. 安全先于体验

这是训练工具，不是治疗。每个页面都不能让人误以为能在这里得到心理帮助。声明、「需要帮助？」入口、风险话题的边界，见 [`../safety.md`](../safety.md)。体验再顺，也不删这些。

## 2. 对话是用户的，不是我们的

- 我们的服务器不存对话。
- 设备上存不存，用户说了算。如果存（待决策 D3），第一次存之前告诉用户，随时能一键删。
- 对话要经过第三方 AI 模型服务，我们在 Onboarding 和练习前都说清楚。
- 不做账号。没有账号，就没有云端数据可泄露。

## 3. 一次练习是一个闭环

简介 → 会谈 → 督导报告 → 下次练什么 → 再练一次。每一页都要回答「下一步做什么」，不留死胡同。

## 4. 像一位好督导，不像一个游戏

用户是专业学员。我们：

- 不发徽章，不搞连胜，不排行。
- 不打总分（MVP 已定）。进度按技能看，用原话说话。
- 语气温和、直接。指出问题，也给出可以换成的说法。

## 5. 少即是多

- 一页只做一件事。主按钮只有一个。
- 第一次练习之前，最多 3 页引导。能跳过的都能跳过（声明除外）。
- 新功能先问：它让练习闭环更好吗？不是就放后面。

## 6. 双语是一等公民

- 界面中英文同时做完，不留漏翻。
- 文案先写中文，再写英文。两边意思一致，不逐字翻译。
- 病例先中文；英文病例在完整版。

## 7. 开放

代码和文档在 GitHub 上公开（MIT）。App 的「关于」页写明这一点，并给出反馈渠道。
