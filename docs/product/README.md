# 产品说明 — 聆镜 PSYGYM App

这一组文档写 App 应该是什么样：有哪些页面、每页放什么、说什么话、按什么顺序做。App 成员照着做，测试照着测，聆镜团队照着提意见。

| 文档 | 写什么 |

| [information-architecture.md](./information-architecture.md) | 页面地图和导航。 |
| [onboarding.md](./onboarding.md) | 第一次打开 App 的引导，逐页写清楚。 |
