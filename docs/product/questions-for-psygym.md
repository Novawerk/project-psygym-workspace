## A. 临床判断（请心理学同事定）

### A1. 「伤害性的话」的范围和次数

- **背景：** AI 来访者和督导现在用同一个范围（[`safety.md`](../safety.md) §3）：辱骂、羞辱；贬低、嘲讽、不耐烦，说来访者矫情、小题大做，拿来访者和「更惨的人」比；性骚扰；歧视；鼓励自伤或伤人。挑战想法、直面、复述、正常化，以及新手常见的说教、劝来访者别难过，都不算。AI 来访者在同一场里**第二次**遇到时，会结束会谈；督导把它单独列出来，排在风险筛查之后。
- **新加的两类（2026-10-15）：** 病例里有了创伤经历以后，真模型测试里出现了两种情况，我们先定为算伤害性的话：
  - 来访者已经拒绝细说后，咨询师仍反复追问创伤经历的细节；
  - 指责受害者，例如「你当时为什么不反抗」。
  
  温和地问起创伤经历、来访者没有拒绝时接着问，不算。
- **要问：**
  1. 这个范围合适吗？「不耐烦」「说矫情」这类话也算进「第二次就结束会谈」，会不会太严？
  2. 新加的两类合适吗？「反复追问」从第几次算起，怎么和正常的探索区分？
  3. 「第二次」这个次数合适吗？
- **我们的倾向：** 范围保持现在这样。新加的两类保留：对有创伤经历的真实来访者，这两种话的伤害和羞辱一样大。
- **答案：**

### A2. 中途提示里的「风险提醒」会不会替学员做了判断

- **背景：** 会谈中途看督导时，如果来访者出现过风险线索、学员还没问过安全，提示的第一条是「可以找机会问一下安全」，并给一句问法（[live-supervision.md](./live-supervision.md)）。
- **要问：** 这样提醒，会不会让学员依赖提示，练不到「自己发现风险」？要不要只在会谈后的完整报告里说？
- **我们的倾向：** 保留。漏掉风险筛查的代价比少练一次大；学员也可以在「我的」里关掉中途提示。
- **答案：**

### A3. 风险筛查的触发条件宽不宽

- **背景：** 来访者只要出现一个抑郁或焦虑线索（如「觉得自己没用」「躺到中午」），而学员整场没有直接问过安全、自伤或自杀，督导报告就把「没有做风险筛查」列为第一条需要改进（[`safety.md`](../safety.md) §4）。1–2 轮的短会谈也会触发。
- **要问：** 初次会谈是否都应该做风险筛查？这个条件太宽还是合适？
- **答案：**

### A4. 「能否承接 / 转介」怎么判断

- **背景：** 你们说初次会谈的主要任务之一是判断能不能接这个来访者。我们打算在督导标准里加一个要点（技能 id 预留为 `intake_decision`），并在简介页写明「初次会谈」（[session-stages.md](./session-stages.md)）。
- **要问：**
  1. 这个判断在对话里通常怎么体现？是学员在会谈中说出来（例如说明接下来怎么安排、需要时提转介），还是会谈后自己判断？
  2. 学员没做到时，督导应该在「需要改进」里提，还是在「下次练什么」里提醒？
  3. 多少轮以上才要求？
- **答案：**

### A5. 练习记录存在学员手机上，有没有顾虑

- **背景：** 对话和报告默认存在学员自己的手机上，可以关、可以删，不上传，没有加密（[ADR 0005](../decisions/0005-local-practice-history.md)）。你们回信说大体同意。
- **要问：** 还有没有具体的顾虑？例如学员把手机给别人看、在公共场合打开。
- **答案：**

## D. 咨询师朋友试用

### D1. 怎么收集反馈

- **我们的建议：**
  1. 每位试用者拿一个邀请码（按批次发，例如「聆镜试用第一批」）。
  2. 每练完一场，App 报告页可以点 👍/👎 加一句话（已有，会转到我们内部的 Slack）。
  3. 试用一周后，请他们填一次下面的问卷，用一个国内能打开的问卷工具（例如腾讯问卷或金数据），由聆镜发链接。
  4. 有更多想说的，约 20 分钟视频聊一次，我们记笔记。
- **要问：** 你们觉得这样可以吗？问卷由谁发、谁汇总？

### D2. 问卷草稿（试用一周后填）

> **说明：** 请不要在问卷里粘贴真实来访者的任何信息。App 里的来访者都是虚构的，截图可以直接贴。

**关于你**

1. 你现在是：在读学生 / 执业 3 年内 / 执业 3 年以上 / 督导或老师 / 其他
2. 你平时主要用哪种取向？（可多选）CBT / 精神分析 / 人本 / 家庭治疗 / 其他
3. 这一周大概练了几场？0 / 1–2 / 3–5 / 6 场以上

**AI 来访者**

4. 来访者像不像真实的来访者？（1 很不像 — 5 很像）
5. 哪个病例最像、哪个最不像？为什么？
6. 有没有哪一句让你觉得「真人不会这么说」？请写下来，或者截图。

**督导反馈**

7. 督导报告指出的问题，你作为咨询师（或督导）同意吗？（1 很不同意 — 5 很同意）
8. 报告有没有漏掉重要的问题，或者说错了？请举一个例子。
9. 会谈中途看督导提示，对你有帮助吗？（没用过 / 1 没帮助 — 5 很有帮助）
10. 报告的长度合适吗？太短 / 合适 / 太长

**整体**

11. 你会推荐给正在学习的同行或学生吗？（0 不会 — 10 一定会）
12. 要让你愿意推荐，最缺的一样东西是什么？
13. 用的过程中有没有让你不舒服、或者担心安全的地方？
14. 还有什么想告诉我们的？

**可以联系你吗？** 愿意的话留一个联系方式，我们约 20 分钟聊一次。（选填）
