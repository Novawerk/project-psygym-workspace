# 内容分级（草稿）

我们的用户是成年的咨询师和学员。病例会涉及抑郁、焦虑和消极念头，不描述自伤方法。建议两边都分到**成人档**，这样也能减少未成年人把它当倾诉工具的风险。

## Apple · Age Rating（App Information → Age Rating）

Apple 2025 年起换成 4+ / 9+ / 13+ / 16+ / 18+ 五档。问卷每年会变，下面按题意写，提交时对着当时的题目逐条选。ASC 首页有一条提示：年龄分级里新加了社交媒体相关的问题，也要答。

| 题目 | 建议答案 | 理由 |
|------|----------|------|
| Cartoon or Fantasy Violence | None | |
| Realistic Violence | None | |
| Prolonged Graphic or Sadistic Realistic Violence | None | |
| Profanity or Crude Humor | None | 来访者被骂时会受伤、会沉默，不会对骂（[safety.md](../safety.md) §3） |
| Mature or Suggestive Themes | **Infrequent / Mild** | 抑郁、消极念头 |
| Horror / Fear Themes | None | |
| Medical or Treatment Information | **Infrequent / Mild** | 督导反馈会谈咨询技术、风险筛查，但不给诊断或治疗建议 |
| Alcohol, Tobacco, or Drug Use or References | None | 以后病例如果涉及物质使用，要改 |
| Simulated Gambling / Contests | None | |
| Sexual Content or Nudity | None | |
| Unrestricted Web Access | No | |
| User-Generated Content / Messaging and Chat | 如实写：**用户和 AI 对话，不和其他用户交流** | 如果问卷单独问 AI 聊天机器人，选 Yes |
| Social media 相关的新问题 | No | 没有动态、关注、私信、公开主页 |
| Advertising | No | |
| Parental Controls / Age Assurance | No | |
| Health or wellness topics | 如果有这题：Yes | |

问卷算出来大概是 13+ 或 16+。**建议手动调高到 18+**（问卷最后可以选更高的档）。

## Google Play · 其他 App content

| 项 | 建议 |
|----|------|
| **Target audience and content** | 只选 **18 and over**。不进 Families 计划 |
| **Ads** | No ads |
| **App access** | 部分功能需要权限：给审核员一个专用邀请码，写清楚在哪输入（用新邮箱登录、输完验证码后的 L3 页）。邀请码由用户填在 Play，不进 git |
| **Health apps declaration** | 我们不是给患者用的健康 App。按 Play 当时的选项，选最接近「医学 / 心理学教育培训」的那一项。不要选面向消费者的心理健康、情绪追踪或治疗类。如果没有合适的选项，选「My app does not have any health features」，并在 App 描述里写清楚是训练工具。提交前要用户确认 |
| **Government apps / Financial features / News** | No |
| **Data safety** | 见 [privacy-labels.md](./privacy-labels.md) |
| **Privacy policy** | 见 [testing.md](./testing.md) |
