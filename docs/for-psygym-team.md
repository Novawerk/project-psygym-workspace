我们（Novawerk）负责开发。AI 来访者演得像不像、督导说得对不对，靠你们写的内容。这一页说清楚要交什么、什么时候交、怎么交。

> **2026-10-15 起，病例和督导标准在后台编辑：** `admin.psygym.novawerk.io`。写草稿、预览、试聊、发布、回滚都在后台，App 一分钟内用上新发布的版本。仓库里的 `content/` 不再是线上来源，提 PR 改那里的文件不会改到 App。见下面「怎么交」。

## 还请你们确认三件事

1. **风险筛查的条件。** 督导什么时候必须指出「没有做风险筛查」？我们现在的条件是：来访者只要出现一个抑郁或焦虑线索（比如「觉得自己没用」），而咨询师整场没有直接问过安全、自伤或自杀，督导报告就把它列为第一条需要改进的地方。初次会谈是否都应该做风险筛查？这个条件太宽还是合适？详见 [`docs/safety.md`](./safety.md) 第 4 节「督导层面」。
2. **求助热线。** App 的「需要帮助？」页要列各地的心理援助热线。请给我们核实过的号码和来源（至少中国大陆，最好也有德国）。拿到之前，这一页只显示不带号码的通用文字。
3. **安全文档。** [`docs/safety.md`](./safety.md) 里标了「待聆镜确认」的地方，请帮我们看一遍。还有一件新的：练习对话和督导报告会存在学员自己的手机上（可以关、可以删，不上传）。从心理学角度，你们对这一点有没有顾虑？另外，学员在报告底部点的 👍/👎 和写的一句话会发给我们（转到我们内部的 Slack 频道），不含对话。

## 怎么写

1. 在后台点「新建病例」，草稿会按 [`content/README.md`](../content/README.md) 的模板预填。改已有的病例或督导标准，直接打开它。
2. 把 `<尖括号>` 换成内容。拿不准的写「待定」。
3. 写成给演员看的角色说明：多用来访者的原话，少用术语。
4. 写完按模板下面的自查清单过一遍。

大概每个病例 1–2 小时，督导标准 2 小时。

## 怎么交

**在后台写、在后台发布。**

1. **账号：** 后台账号由 Novawerk 开通。用 Google 账号登录，你们的心理学同事是「编辑」：能写草稿、试聊、发布、回滚。建议给这个 Google 账号开两步验证。
2. **写：** 卡片信息中英并排，英文可以空着（App 英文界面会显示中文）；给 AI 的角色说明只写中文。随时「保存草稿」，草稿只在后台看得到，App 看不到。
3. **试：** 点「预览」看病例卡片和简介页的样子；「试聊」用草稿和 AI 来访者聊几句，看演得对不对。试聊不保存，不计入统计。
4. **发布：** 校验通过后点「发布」，App 一分钟内用上。每次发布都留记录（谁、什么时候、哪个版本），并在我们内部的 Slack 频道发一条通知（只有病例 id、版本号和角色）。
5. **改错了：** 在「版本历史」里选一个旧版本，「恢复成这个版本」。恢复也是一次发布，旧版本不会删。

可以自己审自己，发布前不用等别人。拿不准的内容，先存草稿，告诉我们一起看。

**打不开后台？** 在中国大陆，Google 的登录页可能打不开。遇到了请告诉我们，我们再加邮件验证码登录。这期间也可以把内容发给我们（Word、飞书文档、Markdown 都行），我们代为录入，再请你们在后台确认。

**仓库里的 `content/`：** 是后台已发布版本的副本，留底用。GitHub 自动同步上线之前，每次发布后由我们导出一次、开 PR 更新。请不要提 PR 改这里的文件，改了也不会到 App。

## 请记住

- 只写虚构人物。不要用真实来访者的信息，哪怕改了名字。
- 这是训练工具，不是治疗。病例不写急性危机。
- 临床内容由你们定。我们不改，有疑问会来问。

有问题随时找我们。
