# Demo 脚本 — 2026-10-18

15 分钟。我们给聆镜团队演示 MVP：选病例、和 AI 来访者对话、看督导报告，最后听他们的反馈。

这份脚本是验收清单 F3 的交付物。

病例用占位病例（占位病例名，以 App 为准）。聆镜的定稿病例到了以后，我们换成正式病例，台词按新病例微调。

## 分工

- **操作**：一人拿手机操作，屏幕投到大屏。
- **讲解**：一人讲，按下面的时间走。
- **记录**：一人记聆镜的反馈和现场出的问题，会后写进看板。

## 时间线

| 时间 | 环节 |
|------|------|
| 0:00–1:00 | 开场 |
| 1:00–2:30 | 首页、声明、选病例 |
| 2:30–8:30 | 一场练习（8 句台词） |
| 8:30–11:00 | 看督导报告 |
| 11:00–15:00 | 收集反馈（5 个问题） |

## 1. 开场（1 分钟）

> 新手咨询师缺练习，也缺督导。聆镜 PSYGYM 让他们和 AI 扮演的来访者练一场，结束后拿到一份 AI 督导反馈。今天我们走一遍完整的练习。

## 2. 首页、声明、选病例（1.5 分钟）

1. 打开 App，停在首页。指出免责声明：这是练习工具，不是治疗。
2. 点占位病例（占位病例名，以 App 为准）。停在练习前声明，读出两点：对话会发给第三方 AI 模型服务处理、我们的服务器不保存对话；这不是临床意见。
3. 点「我知道了」，进入对话。
4. 指给大家看会谈页的「需要帮助？」入口：点开是求助信息。真有人在危机中，我们指向专业帮助，不由 AI 接。

顺带提一句：界面可以切英文（设置页），今天用中文演示。

## 3. 一场练习（6 分钟）

操作的人照着下面输入。来访者每次怎么回，由 AI 决定，我们不预设。来访者回完再输入下一句。

台词里**故意放了好的和不好的做法**，让督导报告两边都有东西可写。讲解的人在输入时**不要点破**哪句是错的，留到看报告时揭晓。

| # | 咨询师输入 | 设计意图 |
|---|-----------|----------|
| 1 | 你好，欢迎你来。今天想从哪里聊起？ | ✅ 开放式开场 |
| 2 | 听起来这段时间你很累，连早上起床都变得很难。 | ✅ 共情、复述感受 |
| 3 | 你可以试试每天早点睡，再去跑跑步，会好很多的。 | ❌ 过早给建议 |
| 4 | 你睡得好吗？吃饭正常吗？和家里人关系好吗？ | ❌ 连续封闭式提问，像在问诊 |
| 5 | 刚才你说「我又搞砸了」，那一刻你脑子里还闪过什么？ | ✅ 抓自动思维 |
| 6 | 有什么证据支持「我很没用」这个想法？又有什么证据不太支持它？ | ✅ 苏格拉底式提问 |
| 7 | 有时候人特别累的时候，会觉得活着没意思。你有没有过这样的想法？ | ✅ 直接、平静地评估风险 |
| 8 | 我们今天时间差不多了。你觉得今天聊下来，哪一点对你最有用？ | ✅ 总结、请来访者反馈 |

**现场调整：**

- 第 2、5、6 句要贴着来访者刚说的话。示范里的「起床很难」「我又搞砸了」「我很没用」只是例子，现场换成来访者刚说过的感受或原话。
- 来访者回得太短或跑题，不追，按顺序往下走。8 句都输完就结束。
- 第 7 句后，来访者的回答取决于病例设定。无论怎么答，接第 8 句。

## 4. 看督导报告（2.5 分钟）

1. 点「结束并查看督导」。等报告逐字出来，大约 30–60 秒。等的时候讲：报告按 CBT 督导标准生成，标准由聆镜定稿。
2. 报告出完，按三部分讲：
   - **做得好的地方**：应该能看到第 2、5、6、7 句里的某几句被原话引用。
   - **需要改进的地方**：应该能看到第 3 句（过早给建议）和第 4 句（连续封闭式提问），每条给了替代说法。
   - **下次练什么**：一到三个具体技术。
3. 指出：每条都引用了咨询师的原话；最后一行写明「这份反馈由 AI 生成，仅供练习参考」。

报告没抓到第 3、4 句时，不掩饰，照实说：「这一条它漏了，正是我们需要聆镜帮我们调的地方。」然后记下来。

## 5. 收集反馈（4 分钟）

讲解的人逐个问，记录的人逐字记。

1. **像不像？** 这位 AI 来访者像一个真实的抑郁来访者吗？哪一句最不像？
2. **督导准不准？** 报告指出的问题，你作为督导会同意吗？有没有漏掉或说错的？
3. **能不能用？** 如果你带一个新手咨询师，你会让他用这个练习吗？练多少次？
4. **缺什么？** 要让你愿意推荐给学员，最缺的一样东西是什么？
5. **下一个病例？** 定稿病例还需要我们怎么配合？10/14、10/16 两个时间点的节奏合适吗？

## 6. 出问题怎么办

| 情况 | 怎么做 |
|------|--------|
| 会场网络不行 | 切到手机热点。还不行，播放提前录好的完整练习视频。 |
| 来访者回复很慢或报错 | 读出 App 的友好提示，点重试。连续两次失败就播录屏。 |
| 来访者跳出角色或给建议 | 不回避，对大家说：「这里它跳出了来访者的角色，我们会修。」记录人记下那一轮，标验收 B1/B2。 |
| 报告没有三部分或没引用原话 | 对大家说：「报告这里不够好，我们会调。」记录人记下，标验收 C1/C2。 |

## 7. Demo 前准备

- [ ] 按 [`mvp-acceptance.md`](./mvp-acceptance.md) F 节，在 demo 用的两台手机上走一遍。
- [ ] 用这份台词完整彩排至少两次，确认督导报告能抓到第 3、4 句。抓不到就和后端一起调督导提示词，不改台词去迁就。
- [ ] 提前录一场完整练习的屏幕视频，放在操作手机和笔记本上各一份。
- [ ] 投屏线、充电线、热点都试过。
- [ ] 正式病例到了以后，换病例、更新本页台词、再彩排一次。
